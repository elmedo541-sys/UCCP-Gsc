🎬 FEATURE OVERVIEW:
═══════════════════════════════════════════════════════════════════════════

Administrators can now manage homepage images that automatically cycle in a 
beautiful slideshow with 4-second intervals. Each image can have custom title 
and description text displayed as an overlay.


✨ KEY FEATURES:
═══════════════════════════════════════════════════════════════════════════

✅ Admin Image Management
   - Upload new homepage images (up to 10MB)
   - Set custom title and description for each image
   - Control display order (determines slideshow sequence)
   - Activate/deactivate images (hide without deleting)
   - Delete unwanted images

✅ Automatic Slideshow
   - 4-second auto-advance between images
   - Smooth fade transitions (500ms)
   - Circular navigation (loops back to first image)
   - Slideshow indicators showing current position
   - Clickable indicators for manual navigation

✅ Responsive Design
   - Works on all devices (mobile, tablet, desktop)
   - Optimized image loading with crossOrigin support
   - Beautiful gradient overlay for text readability
   - Maintains aspect ratio across screen sizes


🎯 HOW TO USE:
═══════════════════════════════════════════════════════════════════════════

FOR SUPER ADMINS:

1. **Access Homepage Images Manager**
   - Log in as Super Admin
   - Go to Admin Dashboard
   - Click "Manage Homepage Images" button in header

2. **Add New Image**
   - Click "Add New Image" button
   - Select image file (JPG, PNG, GIF, WEBP - max 10MB)
   - Enter title (e.g., "Welcome to GSC Members Profile Registration")
   - Enter description (e.g., "Join our community...")
   - Set display order (1, 2, 3... determines sequence)
   - Click "Upload Image"
   - Wait for upload progress (shows percentage)

3. **Manage Existing Images**
   - View all uploaded images in grid layout
   - Each card shows:
     * Image preview
     * Title and description
     * Display order number
     * Active/inactive status
   
   Actions available:
   - **Hide** - Deactivate image (won't show on homepage)
   - **Show** - Activate image (will appear in slideshow)
   - **Delete** - Permanently remove image

4. **Arrange Slideshow Order**
   - Images display in order: 1, 2, 3, 4...
   - Lower numbers appear first
   - Edit display order when adding images
   - Reorder by deleting and re-adding if needed

5. **View Changes**
   - Visit homepage to see slideshow in action
   - Images cycle automatically every 4 seconds
   - Text overlays show your custom titles/descriptions


FOR VIEWERS:
   - No access to Homepage Images Manager
   - "Manage Homepage Images" button not visible
   - Can view slideshow on public homepage like everyone else


📋 HOMEPAGE SLIDESHOW BEHAVIOR:
═══════════════════════════════════════════════════════════════════════════

**Automatic Cycling:**
- Every 4 seconds, slideshow advances to next image
- Fade-out transition (500ms)
- Image changes
- Fade-in transition (500ms)
- Repeats continuously while user is on homepage

**Manual Navigation:**
- Dots at bottom show number of images
- Current image has expanded dot
- Click any dot to jump to that image
- Auto-cycling resumes after manual selection

**Single Image:**
- If only 1 active image, no cycling occurs
- No indicators shown
- Image displays statically

**No Images:**
- Default church building image displays
- Default text: "Welcome to GSC Members Profile Registration"
- Default description: "Join our community and stay connected..."

💾 DATABASE STRUCTURE:
═══════════════════════════════════════════════════════════════════════════

Table: homepage_images

Columns:
- id (UUID) - Primary key
- image_url (TEXT) - Full URL to uploaded image
- title (TEXT) - Custom title text (nullable)
- description (TEXT) - Custom description text (nullable)
- display_order (INTEGER) - Sorting order (default: 0)
- is_active (BOOLEAN) - Show/hide flag (default: true)
- created_at (TIMESTAMPTZ) - Creation timestamp
- created_by (UUID) - Admin who uploaded (foreign key)
- updated_at (TIMESTAMPTZ) - Last update timestamp

Indexes:
- idx_homepage_images_order: (display_order ASC, created_at DESC)

Security:
- Row Level Security (RLS) enabled
- Admins can manage all images
- Public can only view active images

⚙️ TECHNICAL SPECIFICATIONS:
═══════════════════════════════════════════════════════════════════════════

**Slideshow Timing:**
- Interval: 4000ms (4 seconds)
- Transition duration: 500ms
- Total cycle time: 4.5 seconds per image

**Image Requirements:**
- Max file size: 10MB
- Supported formats: JPG, JPEG, PNG, GIF, WEBP
- Recommended dimensions: 1920x600px or wider
- Aspect ratio: 16:9 or wider for best results

**Upload Process:**
1. Select file (client-side validation)
2. Request presigned URL from edge function
3. Upload directly to cloud storage via XHR
4. Track upload progress (0-100%)
5. Save metadata to database
6. Refresh image list

**Performance:**
- Images cached by browser
- Lazy loading enabled
- Optimized transitions
- Minimal memory footprint
- CDN-delivered assets


🐛 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════

**Problem: Upload fails**
Solution:
- Check file size (must be under 10MB)
- Verify file format (JPG, PNG, GIF, WEBP only)
- Check internet connection
- Try refreshing page and re-uploading

**Problem: Images don't appear on homepage**
Solution:
- Verify image is marked as "Active" (not hidden)
- Check image URL is valid
- Refresh homepage (hard refresh: Ctrl+F5)
- Check browser console for errors

**Problem: Slideshow not auto-advancing**
Solution:
- Ensure you have 2+ active images
- Check browser JavaScript is enabled
- Refresh the page
- Clear browser cache

**Problem: "Manage Homepage Images" button not visible**
Solution:
- Verify you're logged in as Super Admin (not Viewer)
- Only Super Admins can access this feature
- Check user role in database

**Problem: Image appears stretched or distorted**
Solution:
- Use higher resolution images (min 1920px wide)
- Maintain 16:9 aspect ratio or wider
- Check original image quality
- Re-upload at higher resolution
