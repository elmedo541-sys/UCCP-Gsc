📋 ISSUE DESCRIPTION:
═══════════════════════════════════════════════════════════════════════════

When users tried to register, they received an error:
  ❌ "invalid input syntax for type date: ''"

This occurred when optional date fields (like mother's birthday, father's 
birthday, or date of marriage) were left empty in the registration form.


🔍 ROOT CAUSE:
═══════════════════════════════════════════════════════════════════════════

PostgreSQL DATE columns accept:
  ✅ Valid dates: '2000-01-15'
  ✅ NULL values: null
  ❌ Empty strings: '' (REJECTED!)

The form was sending empty strings ("") for optional date fields instead of 
NULL values, causing PostgreSQL to reject the insertion.


✅ SOLUTION IMPLEMENTED:
═══════════════════════════════════════════════════════════════════════════

Added data sanitization before database insertion:

Before:
  const { data: personData, error: personError } = await supabase
    .from('people')
    .insert([formData])  // ❌ Empty strings cause error
    .select()
    .single();

After:
  // Sanitize form data - convert empty strings to null for date fields
  const sanitizedFormData = {
    ...formData,
    date_of_birth: formData.date_of_birth || null,
    date_of_marriage: formData.date_of_marriage || null,
    mother_birthday: formData.mother_birthday || null,
    father_birthday: formData.father_birthday || null,
  };

  const { data: personData, error: personError } = await supabase
    .from('people')
    .insert([sanitizedFormData])  // ✅ Null values accepted
    .select()
    .single();


📊 DATE FIELDS AFFECTED:
═══════════════════════════════════════════════════════════════════════════

✅ date_of_birth       - REQUIRED field (always has value)
✅ date_of_marriage    - Optional (converted: "" → null)
✅ mother_birthday     - Optional (converted: "" → null)
✅ father_birthday     - Optional (converted: "" → null)
✅ child_birthday      - Optional (already handled correctly)
