========================================
ORGANIZATION FILTER FEATURE
========================================

This document describes the clickable organization filter feature in the Admin Dashboard.

========================================
FEATURE OVERVIEW
========================================

The admin dashboard now has clickable organization cards that allow filtering the people list by organization.

Key Features:
✅ Click any organization card to filter members
✅ Visual indicator shows active filter (colored ring)
✅ People list updates instantly
✅ Export respects active filter
✅ Filter count shown in table header
✅ Smooth transitions and hover effects
✅ Names sorted alphabetically A-Z

========================================
HOW TO USE
========================================

1. LOGIN as admin
   - Go to /admin/login
   - Login with admin credentials

2. VIEW DASHBOARD
   - See 6 organization cards at the top:
     • Total People (all members)
     • CYAF (Christian Young Adult Fellowship)
     • CYF (Christian Youth Fellowship)
     • CWA (Christian Women Association)
     • UCM (United Church Men)
     • Children

3. CLICK TO FILTER
   - Click any organization card
   - People list shows only that organization
   - Active card shows colored ring border
   - Table header shows: "(Filtered: CYAF - 16 members)"

4. VIEW ALL AGAIN
   - Click "Total People" card
   - Shows all members
   - Ring border appears on "Total People"

5. EXPORT FILTERED DATA
   - With filter active, click "Export to Excel"
   - Only filtered members are exported
   - Example: If CYAF is active, only CYAF members exported

========================================

========================================
TECHNICAL DETAILS
========================================

State Management:
- organizationFilter: string | null
  • null = show all
  • 'CYAF', 'CYF', 'CWA', 'UCM', 'C' = filtered

Filtering Logic:
const filteredPeople = (organizationFilter 
  ? people.filter(p => p.organization === organizationFilter)
  : people
).sort((a, b) => {
  const nameA = a.full_name?.toLowerCase() || '';
  const nameB = b.full_name?.toLowerCase() || '';
  return nameA.localeCompare(nameB);
});

Sorting:
- All names sorted alphabetically A-Z
- Case-insensitive sorting (a = A)
- Works with both filtered and unfiltered lists
- Uses localeCompare for proper alphabetical order

Card Click Handler:
onClick={() => setOrganizationFilter('CYAF')}

Active Card Styling:
className={`cursor-pointer transition-all hover:shadow-lg ${
  organizationFilter === 'CYAF' ? 'ring-2 ring-blue-600' : ''
}`}
